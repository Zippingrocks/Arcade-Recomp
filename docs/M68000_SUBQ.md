# MC68000 quick subtraction

The bootstrap translator supports original MC68000 `SUBQ.B/W/L #1..8,Dn`
instructions. The encoded immediate field value zero represents eight.

## Architectural contract

SUBQ subtracts its three-bit quick immediate from the sized destination, writes
the result, and preserves unselected upper data-register bits for byte and word
operations. N and Z describe the sized result, V reports signed overflow, C
reports unsigned borrow, and X receives the same value as C.

The native helper requires every selected destination bit to be known, computes
with explicitly bounded unsigned arithmetic, marks all five arithmetic flags
known, and rejects invalid widths, registers and immediates without modifying
architectural state. Data-register SUBQ performs no bus access.

Primary source: [Motorola M68000 Family Programmer's Reference Manual](https://www.nxp.com/docs/en/reference-manual/M68000PM.pdf),
SUBQ on printed pages 4-181 and 4-182.

## Original-program evidence

The authenticated EPR-19720 image (SHA-1
`1edaed489a3518ddad85728e416319f940ea02bb`) contains `SUBQ.W #1,D7` at
`0x006003da`. Translation of that instruction is CPU coverage evidence only;
it does not establish sound-board behavior.
