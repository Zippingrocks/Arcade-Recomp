# MC68000 non-updating TST

Date: 2026-10-12. Scope: byte, word and long TST of data registers, address
indirect, displacement, absolute-short and absolute-long operands.

## Architectural contract

TST reads the selected operand without writing it. N and Z describe the sized
value, V and C are cleared, and X retains both its value and knownness. Register
forms require the selected data bits to be known. Indirect and displacement
forms require a known address register. Word and long reads require even
addresses, physical bus addresses wrap independently to 24 bits, and long reads
perform the high-word transaction before the low-word transaction.

A refused read commits no flags, PC or completion count, while an accepted
first word of a subsequently refused long read remains observable on the bus.
This is strict diagnostic behavior, not a reconstructed 68000 bus-error frame.
Updating, indexed, address-register, PC-relative and immediate operands remain
outside this bounded MC68000 subset.

Primary source: [Motorola M68000 Family Programmer's Reference Manual](https://www.nxp.com/docs/en/reference-manual/M68000PM.pdf),
the TST instruction entry and effective-address definitions.

## Verification and original-program evidence

`tests/test_m68k_tst_native.py` contains generated synthetic instructions only.
Three GCC/UBSan tests cover all widths, registers and supported addressing
forms; extension decoding, signed absolute-short behavior, 24-bit wrap, long
read order, exact XNZVC and no-write behavior; truncation, excluded modes,
unknown state, odd addresses and each refused read cycle.

The authenticated, word-swapped EPR-19720 board region (source chip SHA-1
`1edaed489a3518ddad85728e416319f940ea02bb`) contains `TST.B $00608000.L` at
`0x00600470`. Supporting the bounded family grows reset-vector discovery from
188 instructions / 182 translated to 198 / 193 and removes that branch end,
reducing explicit unsupported sites from six to five. The branch rejoins
already translated control flow.

Strict execution remains at 17 instructions before the unknown SCSP byte read
at `0x00100401`; the opt-in common-control model remains at 18 before the unknown
board byte write at `0x00400001`. No value for the tested address or any device
response was supplied by the translator.
