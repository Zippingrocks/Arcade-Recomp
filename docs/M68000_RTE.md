# Native MC68000 exception return

Date: 2026-10-13. Evidence level: synthetic native tests and manufacturer
documentation. The AOT sound CPU now supports original MC68000 RTE opcode
`0x4e73` for a six-byte frame that returns to supervisor mode with trace clear.
This completes the bounded return path paired with the existing autovector
entry; it does not establish continuous sound scheduling or cabinet audio.

## Primary sources

Motorola's [M68000 Family Programmer's Reference Manual](https://www.nxp.com/docs/en/reference-manual/M68000PM.pdf),
printed 6-84 (PDF page 537), specifies RTE's privileged encoding, SR/PC
restoration, condition codes from the saved SR, and stack adjustment. Its
format/offset-word field applies to MC68010 and later listed processors, not
the original MC68000. The [M68000 User's Manual](https://www.nxp.com/docs/en/reference-manual/MC68000UM.pdf),
section 6.2.4 and Figure 6-5, documents the original three-word frame.

The exact data-read sequence is corroborated by Hitachi's manufacturer
[HD68450 DMAC Application Notes, U60](https://bitsavers.trailing-edge.com/components/hitachi/_dataBooks/U60_Hitachi_HD68450_DMAC_Application_Notes.pdf),
HD68000/HD68000Y appendix, printed 177 (PDF page 184), Figure 60,
"RTE Instruction Bus Cycle." Its first three cycles read `SP`, `SP+2`, and
`SP+4`, whose contents are SR, PC high, and PC low. The subsequent two cycles
fetch instructions at the restored PC. The full page and diagram were
visually inspected using the PDF rendering workflow. This is primary
manufacturer evidence for a 68000 implementation, not a Model 2C capture.
The accompanying mask-set bus-error erratum reinforces that intermediate
physical state cannot be inferred from only the successful result.

Only the three stack-data cycles are modeled. Instruction prefetch, physical
bus-error microstate and the Hitachi mask-specific erratum are excluded.
No third-party CPU implementation was copied.

## Runtime contract

RTE reads three explicit words in SR/PCH/PCL order. A7 arithmetic wraps at
32 bits, and each physical bus address is independently masked to 24 bits.
On success, A7 advances six bytes, SR and all its knownness bits are replaced,
and the actual stack-supplied PC becomes the next execution address. X/N/Z/V/C
come from the stack; prior condition-code values and knownness are irrelevant.
One successful RTE increments the completed-instruction count once, whereas
the preceding autovector entry remains a separate, uncounted scheduler boundary.

The helper requires known supervisor state and A7. Unknown A7 or odd stack
addresses stop before data callbacks. Generated execution also retains its
existing current-SR trace, supervisor and interrupt-mask guards. The helper
reports a privilege stop when directly called from known user mode; the
generated global guard still stops user-mode execution as unsupported control.

The restored SR must have S set, T clear and reserved bits clear. All eight
interrupt masks and all 32 condition-code combinations are accepted. A saved
user/trace/reserved SR stops after the first observed word, before reading PC.
This conservative stop is a diagnostic boundary, not a claimed hardware
exception. Unsupported control is never silently cleared or ignored.

All CPU architectural state commits only after the frame succeeds. A bus
provider refusing any word leaves earlier accepted read side effects intact
and latches a stop, so another `step` cannot silently retry the reads. A byte-only
provider cannot satisfy word transactions. Odd or untranslated destinations
are diagnosed on the following step, consistent with existing RTS/branches.
There is no invented return target, frame format word or host exception stack.
Static discovery terminates at RTE; independently established destinations
can be supplied as additional AOT roots.

## Validation and remaining work

Six ROM-free tests in `tests/test_m68k_rte_native.py` pass with GCC 11.4,
strict warnings and UBSan; all six also pass Windows Clang syntax checks
(syntax checks are not Clang runtime execution). They cover every 16-bit
saved-SR pattern, 32,768 old-CCR-knownness/restored-CCR combinations, stack and
bus wrapping, exact word sequence, every refused read, preserved partial read
effects, odd/unknown stacks, byte-only refusal, dynamic return destinations,
and 896 autovector/RTE combinations across every accepted mask/level/CCR.
A request still asserted after RTE is accepted at the next eligible boundary.

User/supervisor stack banking, trace exceptions, physical BERR/address-error
frames, level-7 edge history, continuous interrupt timing and original-board
reset wiring remain unsupported. These tests do not prove an original-ROM
interrupt handler or audible output. Sound CPU estimate remains 5% -> 5%,
audio 0% -> 0%, overall original HOTD1 10% -> 10%; Gates A/B/C remain open.
